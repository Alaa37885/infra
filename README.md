# InfraMind

تطبيق Flutter لإدارة رصد أعطال الطرق في مصر.

## البنية

- `lib/features/road_issues/domain`: كيان البلاغات، عقد المستودع، وحالات الاستخدام.
- `lib/features/road_issues/data`: نموذج التحويل ومصدر بيانات محلي وتنفيذ المستودع.
- `lib/screens`: واجهات التطبيق، وتستهلك البيانات عبر حالة الاستخدام فقط.
- `lib/core/di/app_dependencies.dart`: تركيب الاعتماديات عند بدء التطبيق.

اتجاه الاعتماد هو `presentation -> domain` و`data -> domain`؛ لا تعتمد طبقة المجال على Flutter أو مصدر البيانات. لاستبدال البيانات التجريبية بخدمة فعلية، أضف مصدر بيانات جديدًا وبدّل تنفيذ المستودع في `AppDependencies`.

## التشغيل والاختبار

```powershell
flutter pub get
flutter run
flutter test
```

البيانات الحالية محلية وتجريبية؛ تسجيل الفحص والكاميرا والخرائط ليست متصلة بخدمات فعلية بعد.
